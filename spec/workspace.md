# 工作空间与本地环境

## Alpine 状态和环境预设

Alpine 是应用内的本地运行环境，工作目录为 `/workspace`，内容保存在 Aether 的私有应用存储中。设置中的 Alpine 页面显示运行状态及详细信息：未安装、已就绪、失败；Android 还区分设备架构不支持、安装资源缺失和未就绪。进入页面会检查状态；刷新重新检查。未就绪时可初始化，成功后显示“已就绪”，初始化按钮不可重复使用。初始化失败显示原因，可再次初始化或刷新。

状态区提供重置 Alpine 数据。确认后删除运行环境和其中所有文件；取消不执行。Android 重置同时关闭浏览器、清除预设安装状态及各聊天的 Chrome 开关；若 Alpine 是默认运行时，转用其他已启用的运行时，若没有则不再有默认项。已就绪但尚非默认运行时的 Alpine 可通过“设为默认运行时”选为默认。

环境预设每行显示名称、包含的工具、安装按钮和状态：Python（python3、pip、virtualenv）、Node（nodejs、npm）、Git 与搜索工具（git、ripgrep）、SSH（openssh-client）；Android 另有 Chrome（chromium、noVNC、Noto 字体）。未就绪时不能安装；点击安装后显示进度或速度，完成变为“已安装”且不能重复安装；失败在对应行显示原因，可重新安装。Android 的 Alpine 顶栏有终端、文件和 Chrome 图标：终端和文件在环境就绪时可用，Chrome 在其预设安装后可用。

## Android Termux 与工作目录

Termux 设置进入时检查连接，停留期间定期刷新，顶栏也可手动刷新。就绪时显示已连接；未安装、缺少权限、未允许外部应用或调用失败时显示对应说明及可用操作。安装跳转安装入口；授权和应用权限设置处理调用权限；引导可复制配置命令并打开 Termux，也可直接打开 Termux 或其设置。用户完成外部操作后返回并刷新。Alpine 和 Termux 的文件空间相互独立。

Termux 设置中“单一 Workspace”为默认：所有会话从 `~/.aether/workspace` 开始，上传文件放在其 `uploads/`；选择“独立 Workspace”后各会话使用 `~/.aether/workspaces/` 下自己的目录。此选项针对 Termux，不改变 Alpine 的 `/workspace`。环境变量区按名称和值逐行编辑，可添加和移除；空列表显示一对空输入框。内容随编辑保存，空白行不保留；变量注入每次 Termux bash 命令，例如 HTTP_PROXY 或 HTTPS_PROXY。

默认运行时设置列出 Alpine 和 Termux，以及各自就绪或不可用状态；选择就绪或已经启用的环境作为新聊天的默认环境。聊天中的运行时切换作用于当前会话后续执行，并保留两个环境各自的工作空间。代理设置见 [设置](settings.md)。

命令输出保留与清理设置见 [设置](settings.md)。

Alpine 设置页没有通用环境变量编辑器；提供商配置中的环境变量属于提供商凭证，Termux 页的变量只注入 Termux 命令。

## Agent 的文件与命令操作

Agent 可在当前运行环境读取文本、创建或覆盖文件、精确替换文件中的文字，也可运行 shell 命令。Alpine 还提供列目录、查找文件和搜索内容；Termux 可通过 shell 命令完成这些操作。读取可按行范围获取；精确替换要求原文字唯一匹配，找不到或匹配不唯一时报告失败，不做含糊替换。文件不存在、无权限、搜索或命令执行失败时会返回错误。

命令执行和手动打开的终端是不同会话：Agent 使用当前会话的默认工作目录启动命令，命令中的目录切换不会改变下一次命令的默认目录。命令可以长时间运行，执行中的输出可逐步呈现；指定超时时超时会中止并报告，停止生成会取消当前执行。Agent 命令不是可供用户接续输入的交互终端，等待键盘输入的程序不能依赖用户从聊天输入框回应；需要交互时应使用终端或非交互方式。命令自行启动后台进程后的存活受系统和运行环境生命周期约束，不能保证永久运行。

Alpine 的文件在会话间共享 `/workspace`，关闭聊天或终端不会自动删除文件；重置 Alpine 会移除环境及文件。Android Termux 的独立 Workspace 仅隔离各会话默认目录，并非阻止 Agent 访问其他有权限的路径。对文件的修改保留在所选环境中，不会因切换会话或运行时自动复制到另一环境；应用数据删除或相应环境重置会影响其中保存的数据。

## 交互式终端

从 Alpine 设置打开终端后启动新的交互式 shell，初始目录 `/workspace`。顶部标题默认“Alpine”，终端程序可更新标题。启动期间显示等待，失败显示原因；离开页面结束该终端会话，再打开会启动新的会话，并非连接回原终端；已写入环境的文件仍保留。

Android 顶部返回，终端背景随系统明暗主题变为黑或白。键盘上方有两行可横向滚动的额外按键：ESC、TAB、CTRL、ALT、减号、斜杠、竖线、HOME、END、PGUP、PGDN，以及 KEYB、退格、DEL、INS、方向键和 ENTER。CTRL、ALT 为可切换状态，KEYB 显示软键盘；终端支持选择和复制输出、粘贴输入。



## 文件管理

文件入口打开 Alpine 根目录 `/`。Android 顶栏显示“Alpine Files”和当前完整路径，并有返回、上一级、搜索、刷新和视图选项；根目录时上一级不可用。点击文件夹进入并清除当前搜索；搜索只匹配当前目录中的名称，不递归搜索。加载中显示进度，空目录和搜索无结果有不同提示。

默认按名称排序，文件夹排在文件之前；可改按修改日期或大小降序。Android 可切换列表和网格：列表行显示图标、名称和文件大小或文件夹修改时间，网格显示图标和名称。视图选项只改变当前浏览显示，不移动文件。

点击条目打开；点击条目右侧更多按钮显示单项操作。没有批量选择模式。新建菜单提供文件、文件夹、导入文件和导入文件夹；导入使用系统选择器，文件可多选，复制到当前目录后刷新。新建和重命名弹出名称输入，空名称、`.`、`..` 或包含斜杠的名称无效，同名冲突显示错误。删除须确认，文件夹及其内容会永久删除。操作失败显示错误对话框。

文件菜单提供下载和“用其他应用打开”。下载由系统选择保存位置；用其他应用打开将文件交给系统选择的应用，不把对方的修改自动写回 Alpine。文件夹没有这两个操作。取消系统选择器不执行导入或导出。

打开文本时，UTF-8 文本不超过 8 MiB 才进入编辑器；可编辑、切换自动换行并显式保存，保存失败显示错误。Android 编辑器显示行号、名称和路径，自动换行默认关闭；返回不会自动保存。

Android 预览 PDF、图片、音频和视频；文档、压缩包等不支持内置预览时提供“用其他应用打开”。图片解码或 PDF 页面失败显示错误。打开预览的文件上限为 128 MiB，超过显示错误；超过文本编辑上限的文本转交其他应用。

系统文件应用中可选择 Aether 位置浏览和操作 Alpine 文件，支持读取、创建、修改、重命名和删除等由系统界面提供的操作。Android 仅在 Alpine 已安装时提供该位置，根目录和 `/workspace` 本身不能重命名或删除，`/dev`、`/proc`、`/sys` 系统挂载不对系统文件选择器开放。

## 浏览器与聊天预览

Android 安装 Chrome 预设后，可从 Alpine 设置顶栏打开 Chrome。页面顶部是返回、标题和刷新，下方是可交互的远程画面；远程画面显示完整的浏览器窗口，地址栏、标签和网页导航都在其中操作。点击网页输入位置时调出键盘；启动期间显示进度，连接失败显示原因，可刷新重试。外层返回离开该页面，外层刷新重新连接画面。

聊天输入区在浏览器可用时提供 Chrome 开关；开启后 Agent 可执行浏览器操作，实时浏览器活动出现在聊天消息的预览卡片中，用户可触摸网页。Agent 不能新建、关闭或切换标签页；可导航、点击、输入、滚动、读取页面内容、截图、前进、后退和刷新；也可列出并读取当前页面已加载的资源和已捕获的网络请求，这类检查不导航、不重载页面、不截图。历史回放见 [回复呈现](response-presentation.md)。
